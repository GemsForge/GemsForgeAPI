# UX workflow

The UX agent converts the PO story into an experience contract before implementation.

Each user-facing story should include a wireframe or screen-flow reference, the user goal, responsive behavior, and accessibility acceptance criteria. The Developer implements that contract; QA verifies it at the relevant viewport sizes with keyboard and assistive-technology considerations where applicable.

Minimum accessibility criteria include accessible names and labels, logical focus order, keyboard operation, visible focus, sufficient contrast, usable error states, text scaling, and reduced-motion behavior when animation is present.
